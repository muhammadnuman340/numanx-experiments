Honest limits

What this model does not do

  • "Unseen" is only measured for the held-out categories listed in the config; anything else (other drawing styles, X-rays, memes, ...) is untested.
  • Animal-90 has only about 60 photos per species; look-alikes (zebra→horse, tiger/leopard→cat) are the expected failures and are in the held-out test on purpose.
  • Donkey has the thinnest data of the teacher's test cases (few test photos); read its result with that in mind.
  • If a dataset is reported as skipped in the download step (e.g. Caltech-101 returned "403 Forbidden" in the first run), the model was trained and tested without it.
  • A likely person is always answered "human", so a statue, mannequin or realistic painting of a person may also be called human.
  • One label per picture: a person holding a cat gets a single answer. Handling both would need object detection.
  • Human photos come mostly from web images of adults; children, crowds, unusual poses and very dark photos are less represented.
  • Animals-10 comes from web search and contains some wrong labels, which slightly caps achievable accuracy.
  • Photos of drawings on paper, statues, mannequins and realistic 3D renders are a grey zone for "real".
  • Grad-CAM and similar pictures are clues about the model's behaviour, not proof of how it reasons.
  • Deadline mode caps data and epochs; results vary slightly between runs (GPU randomness) even with a fixed seed.
