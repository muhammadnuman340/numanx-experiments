# Page templates

Every NumanX page follows one of these skeletons, built from the components in this system.

## Home (tools site)

Nav → hero (eyebrow, headline, Search, popular Chips, yellow Stage with three tool results) → categories (ToolCard grid) → Steps → three blog cards (BlogCover) → Footer. Maximum six sections.

## Tool page

Nav → Breadcrumb → title and one line → the privacy line (only if truly local) → **the tool as the hero** (Dropzone or inputs, Tabs for modes, result with Copy/Download, Toast on success) → how to use (Steps) → optional demo clip (Video) → FAQ (Accordion) → related tools (ToolCard ×4) → Footer. On a phone the tool's input is visible without scrolling.

## Category page

Nav → Breadcrumb → title, one line → ToolCard grid (3 / 2 / 1 columns) → Footer.

## Article (blog, guide, comparison)

Nav → Breadcrumb → BlogCover → Article (720px column, Archivo headings, Inter 17px, Table, code blocks with Copy) → "Tools mentioned" ToolCards → two related articles → Footer.

## Sales and service pages

Nav → hero with the phones on the yellow Stage → problem (three short points) → Comparison → free-sample Steps → features → PriceCards → sample work → terms → FAQ → closing yellow panel with a WhatsApp form → Footer.

## Search results, 404 and empty states

Search modal for quick search; a full /search/ page lists ToolCards. The 404 page shows a short message, the Search box and the six categories (EmptyState pattern) and returns a real 404 status.
